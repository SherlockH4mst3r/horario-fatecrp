# 03: Adaptar a grade à tela

**O que entrega:** no computador o aluno vê a semana numa grade de horários; no celular vê a lista por dia, aberta no dia de hoje.
**Bloqueado por:** 01
**Status:** ready-for-agent

- [x] Em tela larga, a grade é uma grade de horários: dias nas colunas, horas na vertical, e cada aula como um bloco do início ao fim.
- [x] Em tela estreita, a grade é uma lista por dia, sem rolagem horizontal.
- [x] No celular, a lista abre no dia de hoje (o domínio recebe a data atual; testado com datas fixas).
- [x] Turma com aula no sábado mostra o sábado; turma sem aula no sábado não mostra a coluna vazia.
- [x] Num dia sem aula, o celular mostra "Sem aulas hoje" com os outros dias logo abaixo.
- [x] No domingo, a lista abre na segunda-feira.
